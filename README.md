# Company Analysis Dashboard | Microsoft Power BI

## Project Overview

This project represents one of my first practical dashboard development projects, created during my learning journey in Business Intelligence and Data Analytics using Microsoft Power BI.

The objective was to analyse company performance through interactive visualisations and present business information in an organised and understandable format.

## Dashboard Modules

### 1. Executive Dashboard
Provides an overview of important business performance indicators.

### 2. Geographical Analysis
Visualises geographical distribution and regional performance.

### 3. Product Analysis
Examines product-level performance, orders, revenue, profits and returns.

### 4. Customer Analysis
Provides insights into customer-related business performance.
